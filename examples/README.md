# Examples

The examples show deterministic MCP workflows over the local CE-RISE solution catalog and deployment artifact manifest.

- `01-design-workflow`: assess a general Digital Passport adoption context, map value-chain information flows, identify value opportunities, recommend a CE-RISE adoption path, generate a roadmap, generalize from reference examples, check update-aware context, plan deployment artifacts, and assess implementation readiness.
- `02-deployment-artifacts`: run a concrete Digital Passport deployment-artifact scenario and inspect the expected Compose/Kubernetes starter outputs.
- `03-update-aware-generation`: generate deployment artifacts while checking current upstream metadata and carrying `version_context` into the result, with an optional model-repository discovery step for newly available CE-RISE data models.
